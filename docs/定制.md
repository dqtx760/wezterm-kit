# 定制

## 先弄清一件事：改哪份文件

`config/` 和 `snippets/` 里全是**模板**。你改它们没用，`install.ps1` 每次跑都会从模板重新生成，你的改动会被冲掉。

**要长期自定义，改生成后的文件：**

| 想改什么 | 改哪个文件 |
|---|---|
| WezTerm 外观、快捷键、分屏 | `~/.wezterm.lua` |
| Shell 行为、别名、函数 | `%APPDATA%\nushell\config.nu` |
| 提示符样式 | `~/.config/starship.toml` |

改之前不用备份——下次跑 `install.ps1` 它自己会先给你存一份 `.bak.<时间戳>`。

---

## 配色

`~/.wezterm.lua` 里一行：

```lua
config.color_scheme = 'OneHalfDark'
```

想看全部自带配色，在 WezTerm 里按 `Ctrl+Shift+P` 打开命令面板，搜 `Color Scheme`。或者命令行列：

```powershell
wezterm --config-file "$HOME\.wezterm.lua" ls-schemes
```

## 字体和字号

两件事都可以直接重跑脚本，不用手改：

```powershell
.\scripts\install.ps1 -FontName "JetBrainsMono Nerd Font" -FontSize 15
```

前提是这个字体系统里装了。查 WezTerm 认到哪些：

```powershell
wezterm --config-file "$HOME\.wezterm.lua" ls-fonts
```

## 背景图

```powershell
.\scripts\install.ps1 -BackgroundImage "D:\path\to\bg.png"
```

路径不存在会跳过并提示，不会写出坏配置。

**图片会被复制一份到 `%LOCALAPPDATA%\wezterm-kit\background.png`，配置里引用的是这个副本。** 所以：

- 装完之后克隆的仓库可以随便删，背景图不受影响
- 但你改了原图不会自动生效，得重跑一次 `install.ps1`
- 想直接改文件，就改 `%LOCALAPPDATA%\wezterm-kit\background.png` 这一个

想调透明度，改生成后的 `~/.wezterm.lua`：

```lua
config.background = {
  {
    source = { File = "D:/path/to/bg.png" },
    opacity = 0.5,        -- 改这里，0 全透明 1 不透明
    ...
  },
}
```

顺带一提：启用背景图时窗口上内边距会自动设成 30 给图让位，不启用就是 2。

## 快捷键

都在生成后的 `~/.wezterm.lua` 的 `config.keys` 里，格式很好懂：

```lua
{ key = "k", mods = "CTRL|SHIFT", action = act.SpawnTab 'DefaultDomain' },
```

改完存盘，WezTerm 默认开着热重载，立刻生效，不用重启。

要是不想热重载（配置写错时会一直弹报错）：

```lua
config.automatically_reload_config = false
```

## 加自己的 AI CLI 快捷命令

两步。

**第 1 步**：在 `snippets/` 下新建 `<命令行名字>.nu`，比如要加 `amp`：

```nu
# amp —— 启动 amp，同时把标签页标题改掉
def am [] {
    wezterm cli set-tab-title "Amp"
    amp __FLAGS__
}
```

`__FLAGS__` 是占位符，开 `-AiCliAutoAccept` 时会被替换。不确定该填什么就留着它，脚本会处理。

**第 2 步**：把名字加进 `scripts/install.ps1` 里的这一行（搜 `foreach ($cli` 就能找到）：

```powershell
foreach ($cli in @('claude', 'qwen', 'codex', 'gemini')) {
```

改成：

```powershell
foreach ($cli in @('claude', 'qwen', 'codex', 'gemini', 'amp')) {
```

重跑脚本。只有本机检测到 `amp` 才会注入，没装就跳过。

## 加自己的 Nushell 别名和函数

直接往 `%APPDATA%\nushell\config.nu` 末尾加。几个例子：

```nu
# 别名
alias ll = ls -l
alias gs = git status

# 带环境变量的函数（--env 表示函数内能改环境变量）
def --env "cdp" [] {
    cd D:\project2026
}

# 带参数的函数
def mkcd [dir: string] {
    mkdir $dir
    cd $dir
}
```

注意：直接往 `config.nu` 加的内容，**下次跑 `install.ps1` 会被覆盖**。脚本会先备份，从 `.bak.<时间戳>` 里捞回来粘回去就行。

要是改动比较多，更省事的做法是把 `install.ps1` 加个 `-SkipApps -SkipFonts` 之后就别再跑了，配置全手工维护。

## 分屏和窗口

现在的行为：新窗格继承当前目录（`domain = 'CurrentPaneDomain'`），窗口启动时只开一个 Shell 标签页，工作目录跟随启动位置。

想回到「启动就拉起一堆标签页」的写法，在 `~/.wezterm.lua` 的 `gui-startup` 里加：

```lua
wezterm.on('gui-startup', function(cmd)
  local tab, _, window = mux.spawn_window({})
  tab:set_title("Shell")

  local t2 = window:spawn_tab({ args = { 'nu.exe' } })
  t2:set_title("Work")
end)
```

**但不建议在这里拉起 AI CLI。** 某个 CLI 没装、或者卡在登录，整个 WezTerm 就起不来了。放进 Nushell 的 `cc`/`qw`/`cx`/`gm` 里更稳。

## 提示符

`~/.config/starship.toml`。想关掉某个模块就加 `disabled = true`：

```toml
[nodejs]
disabled = true
```

想加模块往 `format = """..."""` 里插 `$模块名`。完整文档看 [starship.rs](https://starship.rs/config/)。
