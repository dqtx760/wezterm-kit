# 排错

先跑一遍 `scripts\verify.ps1`，它会告诉你具体是哪一项挂了。

---

## 字体装了，终端里还是没变

**先确认是真没变，还是没重启。** 字体注册表改完，必须**完全退出 WezTerm 进程**再重开——关窗口不算，托盘里可能还留着进程。

如果重启后仍然不对，查两件事：

```powershell
# 1. 字体文件在哪
Test-Path "$env:LOCALAPPDATA\Microsoft\Windows\Fonts\CaskaydiaCoveNerdFont-Regular.ttf"
Test-Path "$env:windir\Fonts\CaskaydiaCoveNerdFont-Regular.ttf"

# 2. 注册表里登记了没有（注意是短名 NF，不是全称 Nerd Font）
Get-ItemProperty 'HKCU:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts' |
    Select-Object -Property 'CaskaydiaCove NF*'
```

**这里有个坑**：Windows 字体注册表里登记的名字是**短名** `CaskaydiaCove NF`，而终端配置里写的是**全称** `CaskaydiaCove Nerd Font`。DirectWrite 两个名字都认，指向同一套字体，所以配置写全称没问题——但你在注册表里搜全称会搜不到，别以为没装上。

直接问 WezTerm 自己最准：

```powershell
wezterm --config-file "$HOME\.wezterm.lua" ls-fonts
```

输出里应该能看到 `CaskaydiaCove Nerd Font` 和它解析到的 `.ttf` 路径。

## 提示符全是方框 / 问号

字体没生效，或者被别的字体顶掉了。按上一节查。

另外确认 Starship 配置里的图标字符（、󰈙 这类）需要 Nerd Font 的 **Symbols** 系列，CaskaydiaCove Nerd Font 自带，不用额外装。

## winget 装不动

**最常见的原因：WezTerm 正在运行。** winget 装不了一个正在跑的程序。完全退出再试。

其他可能：

```powershell
# 源缓存坏了就重置
winget source reset --force
winget source update

# 确认包 ID 还在（Nushell / Starship 两个，WezTerm 只有 Stable 通道才走 winget）
winget show --id Nushell.Nushell
winget show --id Starship.Starship
```

装失败不用重跑整个脚本，手动装完那一个再跑 `install.ps1`，脚本会跳过已装的。

---

## Nightly 下载失败 / sha256 校验不通过

Nightly 是个 45MB 的安装包，从 GitHub 下。挂了通常是网络问题。

**校验不通过**说明文件没下完整（下到一半断流），脚本会中止、不会去装坏的包。直接重跑就行。

**下载不动**的话：

1. 挂上代理再跑：`.\scripts\install.ps1 -ProxyPort 7890`
2. 手动下载安装：[WezTerm-nightly-setup.exe](https://github.com/wezterm/wezterm/releases/download/nightly/WezTerm-nightly-setup.exe)，装完再跑 `.\scripts\install.ps1 -SkipApps` 只装字体和配置
3. 实在下不动就换正式版：`.\scripts\install.ps1 -Channel Stable`（走 winget，快，但版本停在 20240203）

想核对下载的文件对不对，校验值在这里（每天跟着构建更新）：

```powershell
(Invoke-WebRequest 'https://github.com/wezterm/wezterm/releases/download/nightly/WezTerm-nightly-setup.exe.sha256' -UseBasicParsing).Content
```

装完看日志：`%TEMP%\wezterm-nightly-install.log`

---

## 版本号看着像 2024 年的，是不是装错了

看你装的哪个通道：

- **Nightly（默认）**：版本号是 `<日期>-<时间>-<commit>` 格式，比如 `20260829-035000-abc12345`，日期是新的就对了
- **Stable**：`20240203-110809-5046fc22` —— 这是最后一个正式版，自 2024-02 起停更，不是你装错了

查当前版本：

```powershell
wezterm --version
```

Nightly 装完自带更新检查，有新构建时 WezTerm 会自己弹提示，不用手动反复下载。

## Nushell 起不来 / 报语法错

两种可能。

**一是配置文件本身有语法问题**，直接问 nu：

```powershell
nu --config "$env:APPDATA\nushell\config.nu" --env-config "$env:APPDATA\nushell\env.nu" -c 'print "ok"'
```

打印 `ok` 就说明配置没问题，问题在别处。

**二是配置调用了不存在的程序。** 比如 `config.nu` 里注入了 `cc`，但 `claude` 没装——不过 `def` 定义不会在加载时执行，一般不会导致起不来。真出问题就把对应片段注释掉。

改崩了想回退：

```powershell
Get-ChildItem "$env:APPDATA\nushell" -Filter '*.bak.*' | Sort-Object Name
```

挑最新的复制回去。

## `wezterm cli set-tab-title` 报错

这个命令依赖两件事：

1. `wezterm` 在 PATH 里
2. 环境变量 `WEZTERM_PANE` 存在（只有在 WezTerm 里运行才有）

在普通 PowerShell 里跑 `cc`，标题是改不了的（会报 `WEZTERM_PANE` 未设置，但命令本身还是会正常启动）。这不算故障，标签页标题只是没变。

`wezterm` 不在 PATH 的话，重新打开 WezTerm，或者手动把 `C:\Program Files\WezTerm` 加进 PATH。

## 代理设了，但 git / npm 还是连不上

WezTerm 里设的代理只对它拉起的子进程生效。出了这个终端就没有了。

Nushell 里可以临时开关：

```nu
proxy check    # 测一下通不通
proxy unset    # 关掉
proxy set      # 再打开
```

注意这是**当前 shell 会话**生效，新开标签页会回到配置里的默认状态。

---

## `qw` 的 `-y` 参数没效果

对，Qwen Code 0.21.8 **没有**自动接受的参数。老配置里写的 `qwen -y` 不报错，但 `-y` 会被静默忽略。

`snippets/qwen.nu` 里已经是空的，`qw` 就是普通的 `qwen`。等官方支持了再改这一个文件重跑脚本就行。

## 改完 .ps1 脚本突然报语法错

**BOM 掉了。** PowerShell 5.1 解析 UTF-8 无 BOM 的脚本时，会按系统 ANSI 代码页（中文 Windows 是 GBK）解码，中文注释全变乱码，然后报一堆莫名其妙的语法错——报错位置还常常指错行。

用 VS Code 的话看右下角，必须是 **UTF-8 with BOM**。命令行修：

```powershell
$p = '.\scripts\install.ps1'
$t = [IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)
[IO.File]::WriteAllText($p, $t, (New-Object Text.UTF8Encoding $true))
```

注意配置模板（`*.lua` / `*.nu` / `*.toml`）**反过来要无 BOM** —— WezTerm、Nushell、Starship 都按 UTF-8 读，加了 BOM 反而可能出错。

## 想彻底卸载

脚本没有提供卸载命令，因为配置是覆盖写进已有路径的，没法判断哪些是你自己的东西。手动来：

```powershell
winget uninstall wez.wezterm
winget uninstall Nushell.Nushell
winget uninstall Starship.Starship
```

字体去 `设置 → 个性化 → 字体` 里删 CaskaydiaCove Nerd Font。

配置文件（`.wezterm.lua`、`%APPDATA%\nushell\`、`.config\starship.toml`）自己决定留不留，脚本生成的备份都带 `.bak.<时间戳>` 后缀。
